# راهنمای اتصال هوش مصنوعی به KPIMS (فاز ۷)

لایه هوش مصنوعی KPIMS **مستقل از سرویس‌دهنده** است: هر سرویسی که رابط سازگار با
OpenAI داشته باشد، فقط با تغییر تنظیمات وصل می‌شود — بدون تغییر کد.

## پیش‌فرض توصیه‌شده: Ollama محلی (رایگان، آفلاین، بدون فیلترینگ)

مدل روی همان رایانه/سرور اجرا می‌شود؛ داده‌ای از کارخانه خارج نمی‌شود و هیچ
وابستگی به اینترنت یا IP وجود ندارد.

```bash
# 1) نصب Ollama (ویندوز/لینوکس — از سایت ollama.com)
# 2) اجرای سرویس (در لینوکس معمولاً خودکار است)
ollama serve
# 3) دانلود مدل پیشنهادی فارسی‌پسند (یکی کافی است)
ollama pull qwen2.5:7b      # پیش‌فرض KPIMS — متعادل
# گزینه‌های دیگر:
#   ollama pull gemma2:9b
#   ollama pull llama3.1:8b
#   ollama pull aya-expanse:8b
```

سپس در KPIMS: **کاربران و تنظیمات ← هوش مصنوعی** → مقدارها را بگذارید و
«آزمایش اتصال» بزنید (پیش‌فرض‌ها: آدرس `http://127.0.0.1:11434/v1`، مدل
`qwen2.5:7b`). اگر سرویس در دسترس نباشد، سامانه صادقانه «قطع» نشان می‌دهد.

نیاز سخت‌افزاری: مدل 7B حدود ۵ تا ۶ گیگابایت رم آزاد می‌خواهد (۸ گیگ رم کل
حداقل است). روی سرور با رم ۱۶ گیگ، اجرای هم‌زمان برنامه و مدل مشکلی ندارد.

## گزینه جایگزین: درگاه ایرانی سازگار با OpenAI

اگر کیفیت مدل بزرگ‌تر خواستید، در همان صفحه تنظیمات مقدارها را تغییر دهید:

| تنظیم | مقدار نمونه |
|---|---|
| `ai.provider` | `openai-compatible` |
| `ai.baseUrl` | آدرس `v1` سرویس (طبق مستندات همان سرویس) |
| `ai.model` | نام مدل طبق سرویس |
| `ai.apiKey` | کلید شما (به‌صورت مخفی ذخیره می‌شود) |

سرویس‌های ایرانی (مانند AvalAI) از داخل ایران مستقیم در دسترس‌اند و پرداخت
ریالی دارند؛ شرایط و بسته‌های اعتباری را پیش از خرید از وب‌سایت خودشان بررسی
کنید. سرویس‌های خارجی معروف معمولاً IP ایران را مسدود می‌کنند.

## قواعد ایمنی (پیاده‌شده در کد)

- دستیار فقط پیشنهاد می‌دهد؛ **هیچ‌گاه سندی ثبت یا قطع‌بوش نمی‌کند** و خروجی‌اش
  با برچسب «صرفاً پیشنهاد» نمایش داده می‌شود.
- «گزارش هوشمند»: مدل فقط `reportKey` و فیلتر را از فهرست ۱۵ گزارش مجاز
  پیشنهاد می‌دهد؛ گزارش/فیلتر ساختگی رد می‌شود و اعداد همیشه از اجرای واقعی
  گزارش روی دیتابیس می‌آیند.
- هر استفاده در `audit_logs` ثبت می‌شود؛ کلید سرویس در تنظیمات مخفی (isSecret)
  نگه داشته و در نمایش‌ها پوشانده می‌شود.
- «آزمایش اتصال» پروب واقعی HTTP به `/models` سرویس است — موفقیت ساختگی وجود ندارد.

## متغیرهای محیطی (اختیاری — جایگزین تنظیمات دیتابیس)

`AI_ENABLED`, `AI_PROVIDER`, `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`,
`AI_TEMPERATURE`, `AI_TIMEOUT_MS` — اولویت: تنظیمات دیتابیس > محیط > پیش‌فرض.

## Endpointهای API

| مسیر | توضیح | مجوز |
|---|---|---|
| `GET /api/v1/ai/status` | وضعیت واقعی سرویس + فهرست مدل‌ها | احراز هویت |
| `POST /api/v1/ai/assistant` | پرسش و پاسخ عمومی با بافت KPIMS | احراز هویت |
| `POST /api/v1/ai/suggest/document` | بازبینی پیش‌نویس سند (RECEIPT/ISSUE/…) | `inventory.view` |
| `POST /api/v1/ai/report-query` | پرسش فارسی → گزارش واقعی + روایت مدل | `reports.view` |
